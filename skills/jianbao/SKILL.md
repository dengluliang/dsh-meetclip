# 发布会图文简报

一句话进（记录 id 或“最近一条发布会”），飞书文档链接出。

## 产出定义

一份飞书 docx，包含：顶部素材 callout、`概述`、按需出现的 `产品概要 / 价格 / 参数表`、`发布会详情`（按机型或环节 → 官方卖点小节 → 图组）、`素材与时间戳索引`。
全文图片默认 **40–80 张，每小节 2–4 张**。

## 七条硬规则（违反即返工）

1. **只写发布会说了什么。** 不写主观评价、贬褒、预测、传闻、竞品优劣结论。禁用清单见 `references/风格蒸馏.md` §5。
2. **成稿里不允许出现“存疑”“待核实”字样。** 转写里可疑的专名、数字、型号，**先向用户提问澄清**（第 3.5 步），确认后才写；未确认的一律用通称或省略，并写进交付说明的「待确认清单」，**不进正文**。
3. **不写任何与发布会无关的信息。** 会摘记录 id、转写段数、截图张数、文件名、工具名、处理过程一律不出现在文档里。文档只写：发布会名称、源视频、时长、产品与价格、讲者、时间线。
4. **不猜。** 转写没提到的参数写 `（未说明）`，不要用记忆或常识补齐。
5. **不看图写内容。** 图片只做配合；图注只用 `卖点名 @MM:SS`，禁止描述画面。
6. **概述之后紧跟源视频与回看索引。** 文档结构固定为：`概述`（高亮块）→ 源视频播放器（B 站用 `<iframe url="…" type="1"/>`）→ `回看索引`（小节 + 时间区间 + `源地址?t=秒` 可点跳转）→ 其余模块依次向下。**不要在文档最前面加任何“发布会/时间/源视频”之类的信息块。**
7. **不编造链接。** 只用真实的源视频地址与时间戳。

## 执行流程

### 第 1 步 · 定位与取料

**若用户 @ 了 `会摘卡片/` 下的文件**（例如 `/jianbao @今日宜休 AI睡眠科技生态发布会.md`）：先读该卡片拿到 `session_id` 与元数据，再从第 3 条开始取料；卡片里的转写预览只能用于判断结构，正文事实必须回原文核对。

1. 用户给了记录 id → 直接使用；没给 → `meetclip_records(action=list)`，取最近一条 `status=done` 且 `kind` 为 `live` 或 `link_video` 的记录，并向用户确认标题。
2. `meetclip_records(action=get, session_id=...)` 拿时长、转写条数、来源链接；`meetclip_minutes(action=get)` 拿 AI 纪要（有则读，无可跳过）。
3. **分页读全量转写**：`meetclip_records(action=transcript, session_id=..., limit=200, offset=0/200/400...)` 直到读完。只读一遍，边读边在内存里建「时间锚点 → 内容」索引，不要反复重读。
4. `meetclip_status` 取 `locations.dataDir`。本机素材位置：
   - 视频：`<dataDir>/<session_id>/media.mp4`
   - 现成截图：`<dataDir>/<session_id>/shots/`（只有直播/会议录制才有，回放链接通常没有）

### 第 2 步 · 判体裁与开模块

产品发布会与 OS/生态发布会**共用同一套骨架**，靠模块开关适配：

| 模块 | 触发条件 |
|---|---|
| `概述`（高亮块内 3–5 组「标签 + 定性 + 分条」） | 永远，**放在文档最前面** |
| 源视频播放器（`<iframe type="1"/>`） | 永远，紧跟概述 |
| `回看索引`（小节 + 时间区间 + 时间戳跳转） | 永远，紧跟视频 |
| **禁止** 顶部信息块（发布会/时间/源视频/记录 id 之类） | 永远不加 |
| `产品概要`（名称 / 发布时间 / Slogan） | 本场有明确新品与 Slogan |
| `价格` | 本场公布价格 |
| `参数表` | 有硬件参数可对比（本代 vs 上代） |
| `发布会详情` | 永远 |
| `关键能力清单` | OS/生态类推荐；产品类可选 |


### 第 3 步 · 定骨架，写 plan.json

- 二级标题 = 机型 / 环节；三级标题 = **官方卖点名**（如 `Super Live`、`灵盾防窥屏`），不自创分类。
- 每个小节 3–8 条极简 bullet：`关键词 + 数字 + 对比基线`。概述与正文写法细则见 `references/风格蒸馏.md` §2。
- **为每个小节记下时间区间**：起始 = 该小节第一句转写的 `ts`，结束 = 下一小节起始（最后一节取记录时长）。
- 产出 `plan.json`（格式见 `references/文档模板.md` 末节），必须含 `source_url`（源视频地址）与小节时间区间，供配图与回看索引用。

### 第 3.5 步 · 存疑澄清（新增，必做）

把转写里有问题的地方**先列出来问用户**，确认后才进正文：

1. 汇总疑点：产品/型号名、芯片与传感器型号、人名与机构名、异常数字、竞品品牌、口径矛盾。
2. 用 `ask_user_question` 一次性问清，每题给「用通称不写未确认专名（推荐）/ 我提供正确名称 / 保留转写原文」这类选项。
3. 按答复写入。**用户未答复或选择跳过时**：正文用通称（如「智能戒指」「智能温控系统」）或省略该细节，并在交付说明里单列「待确认清单」，绝不把推测写进文档。

### 第 4 步 · 配图

```bash
python3 scripts/frames.py --session-id <id> --plan plan.json --out frames/
```

- **A 源**：`shots/` 有文件时优先用现成截图，按小节时间区间筛选。
- **B 源**：无 shots 时用 `media.mp4` 做 scene 变化检测，只保留画面明显变化的帧（PPT 翻页、演示切换）。
- 自动做近似帧去重，并按每小节上限截断；产出 `frames/manifest.json`。
- 若两源都没有 → 本场不插图，文末注明「本条记录无画面素材」。

### 第 5 步 · 组稿

按 `references/文档模板.md` 写正文模板（图片位置留 `{{IMG:s1}}` 占位），然后：

```bash
python3 scripts/build_doc.py --plan plan.json --manifest frames/manifest.json \
    --template doc_template.md --outdir chunks/
```

它会替换占位符、生成时间戳索引表，并按图片数量自动切成若干 `chunk_NN.md`。

**两个必须记住的坑（已实测）**：

1. **本地图片路径要写四个斜杠**：`file:////Users/...`。飞书 MCP 会剥掉 `file:///`，写三个斜杠会被当成相对路径报 ENOENT，六个都失败。
2. **单次调用 5–12 张图**。40 张一次性提交会返回 `Image patch failed ... 400`，图片块变空且**无法回填**，只能删文档重建。

其它格式要求：

- **概述整体放进高亮块**：`<callout emoji="💡" background-color="light-blue">…</callout>`，内含 3–5 组「加粗标签 + 定性句 + 带数字的分条」。标签按本场重点自定义，不要固定成三个（详见 `references/风格蒸馏.md` §2.2）
- **图片必须分列并排**：`<grid cols="2|3">` + `<column>`，一行 2–3 张；**禁止竖排单列**（一屏只看得见一张图，节奏会垮）
- GFM 表；参数表用 `↑` / `↓` 标升级与退步，单侧变化另一侧写 `—`
- 分块之间留空行；标题不要重复文档标题

### 第 6 步 · 建文档、自检、交链接

1. `chunk_00` → `mcp__feishu__doc_create(title=..., markdown=...)`，拿到 `document_id` / `url`；
   其余 chunk 按顺序 `mcp__feishu__doc_append(document_id=..., markdown=...)`。
   默认省略 `folder_token`（我的云空间根目录），用户指定则传入。
   若返回 `missing_document_title` 警告，在正文首行加 `# 标题` 重试。
2. **检查返回的 `warnings`**：非空说明有内容被降级成纯文本，需把那一块拆小重试，不能当作成功。
3. 自检：
   - 用块接口统计：图片块数应等于 manifest 总数，且**没有 token 为空的图片块**
   - 章节数与 plan 一致
   - **全文搜一遍违禁内容**：`存疑`、`待核实`、`会摘`、`记录 id`、`转写 xxx 段`、`截图`、`session_id`——出现即返工
   - 确认源视频已嵌入、回看索引链接可点
   - 抽查 2 个小节：图是否落在对应卖点下、图注时间戳是否在该小节区间内
   - 全文搜一遍禁用词（`见鬼`、`垃圾`、`抄袭`、`像素级`、`据传`、`// 但`）
4. 交付：文档链接 + 一句话内容摘要 + 图片张数 + 时长；另附「待确认清单」（正文里没写、等你确认后可补的信息）。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 层级 | `简报` | `lite` / `信息提要` / `简报`，控制小节数与 bullet 密度 |
| 图密度 | 每小节 2–4，全文 40–80 | 用户可调；超过 60 张后每次 `doc_create` 分两批写 |
| folder_token | 云空间根目录 | 用户指定归档目录时传入 |
| 参数表 | 自动 | 检测到硬件参数才生成 |

## 失败与降级

| 情况 | 处理 |
|---|---|
| 无 `media.mp4` 且无 `shots/` | 不插图，文末注明；如需结构图可用 mermaid 画板替代 |
| 转写未覆盖价格 | 价格段写「本场未公布价格」，不引用外部信息 |
| 记录仍在转写 | 告知用户进度与 `session_id`，不要产出半成品文档 |
| 文档过长、写入报错 | 先 `doc_create` 写概述与前半部分，再 `doc_append` 追加正文 |
