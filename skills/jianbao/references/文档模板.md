## 二、写作细则（摘自蒸馏结论）

1. **概述的 bullet 必须带数字与对比基线**，不写“大幅提升”“全面升级”这类空话。
2. **一句一事实**，不写过渡句；不用“本次发布会亮点纷呈”“值得关注”等填充语。
3. **参数与价格优先于叙述**：能进表的不写成段。
4. **正文小节沿用官方卖点名**，不要自创分类名（不要写“影像部分”“性能部分”）。
5. **讲者与环节切换必须标**：口误、站台嘉宾、供应商上台、One More Thing 都算信息。
6. **存疑不进正文**：疑似错的专名/数字/型号，先向用户提问澄清（SKILL.md 第 3.5 步）；未确认就用通称或省略，并列入交付说明的「待确认清单」。成稿里不出现「待核实」字样。
7. **禁止**：主观评价、传闻、竞品优劣结论、看图写画面描述（禁用清单见 `风格蒸馏.md` §5）。

## 三、plan.json 格式（第 3 步产出，供配图脚本使用）

```json
{
  "session_id": "dfb8229ad18f",
  "title": "今日宜休 AI 睡眠科技生态发布会",
  "duration": 6370.4,
  "max_per_section": 4,
  "sections": [
    {"id": "s1", "h2": "产品线 A", "h3": "官方卖点名", "start": 78, "end": 214},
    {"id": "s2", "h2": "产品线 A", "h3": "官方卖点名 2", "start": 214, "end": 402}
  ]
}
```

- `start` / `end` 单位为秒，来自转写逐句时间戳。
- `max_per_section` 缺省 4；全文上限在 SKILL.md 第 4 步控制。
- 配图脚本输出 `frames/manifest.json`：`{"s1": [{"file": "...", "ts": 83.2, "score": 0.42}], ...}`
