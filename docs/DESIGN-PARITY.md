# 会摘插件 · 设计重构功能对照（DESIGN-PARITY）

> 目的：证明「摘录墙」与整体视觉重构**没有删减现有功能**。每一行给出旧入口、新入口和验证方式。
> 基线：`docs/MIGRATION-AUDIT.md`、`docs/PARITY.md`。
> 新主页不替代任何旧能力；资料库、设置、搜索、右键和快捷键保留。日历功能已按需求移除（数据保留）。

## 1. 一级导航

| 旧 | 新 | 说明 |
|---|---|---|
| 顶部「记录 / 日历」 | 顶部「首页 / 资料库」 | 首页为默认；资料库=原记录列表/详情；日历移除 |
| 顶栏品牌+状态点+新建+搜索图标+刷新 | 顶栏保留品牌、胶囊导航与搜索入口 | 搜索回到顶栏（`⌘K` 保留）；新建与采集走首页 Hero 的 `＋` 三入口菜单；状态浮层移除 |
| 侧栏底部依赖/模型状态卡 | 状态浮层（引擎/环境/数据目录）+ 资料库保留原有卡片 | 不在首页重复堆状态卡 |
| 列表内标题搜索 | 资料库保留「筛选此列表」；顶栏搜索按钮 / `⌘K` 打开全局搜索 | 两个搜索作用域不同，均保留 |

## 8. 验证锚点（interaction smoke）

- `首页`：Hero 文案、记录卡、金句卡、散落/信息流切换、卡片打开后进资料库并选中该条。
- `资料库`：原列表、详情、标记/截图右键、笔记。
- `新建采集`：三类型、初始 URL。
- `采集`：发布会/视频/会议按输入自动弹出单一内联面板，风格与搜索下拉统一；`设置`：模型/采集两个标签；模型含 Mify Key、拉取模型清单、语音转文字与文字总结（各自可选模型与自定义 API），采集含直播与视频行为；不再出现状态/数据/诊断。
- 后端：`/api/home` 统计、封面优先级、金句、分页、鉴权。

## 9. 已知非阻塞差异

- 首页散落画布是确定性求解的无限画布：Hero 居中，卡片两两避让并避开 Hero；拖过的卡片与图钉固定为障碍，其余卡片松手后让开；筛选/轮询只改变可见性、不重排。手动位置保存在本机 localStorage（`meetclip.scatter.layout.v2`，Hero 居中坐标），旧版偏移量键不再读取。
- 首页封面优先链接缩略图/首张截图；会议无截图时用类型渐变底，不伪造图片。
- 首页暂无独立右键全菜单（打开/复制链接有）；完整菜单在记录详情/资料库。
- 平台适配（Finder/Quick Look/AppKit 文本菜单）仍按 `MIGRATION-AUDIT.md` 的 Web 等价方案。
- Agent UI 不迁移；`meetclip_*` 工具保留。
