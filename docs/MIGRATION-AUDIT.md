# 会摘插件 · 功能迁移审计（对照原生功能清单）

> **2026-11-03 更新：日历功能已按用户要求移除（前端入口/设置/关联）；日历数据、数据库表与后端接口保留，不再暴露 UI。**
>
> 基线：原生会摘 1.0.10-Beta（HEAD `2c94d8a`）；插件 `@meetclip/dsh-meetclip` 0.1.0
> 对照文档：`../会摘App-功能清单.md`、`../会摘App-右键菜单速查表.md`
> 状态：✅ 已实现　🟡 部分/简化　🔵 Web 适配（平台差异，非缺陷）　⬜ 未实现
> 更新时间：2026-11-03

## 0. 结论摘要

- 插件已覆盖原生端的**采集、转写、队列、记录浏览、搜索、笔记、日历、设置、导出**主链路。
- 原生 macOS 专属能力（菜单栏、Liquid Glass、Finder、Quick Look、AppKit 文本菜单、独立窗口）在 Web 中按等价交互适配。
- 已补齐：侧栏多选与右键、记录/标记/截图/发言人/内容区右键、键盘快捷键、时间轴与播放条、转写自动跟随与发言人分组、日程未关联内容混排、笔记格式工具/查找、详情提示条、采集健康提示、侧栏状态卡、直播胶囊与截图灵敏度、采集草稿保留/默认类型/Calendar 关联、日历三来源开关、截图拖拽/批量下载。
- **迁移结论**：对照清单的功能项均为 ✅ 已实现或 🔵 Web 等价适配；无 ⬜ 未实现、无 🟡 阻塞项。剩余仅为视觉打磨、后端不支持的日历高级字段与真机浏览器复核。
